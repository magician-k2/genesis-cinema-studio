# ⚡ GENESIS μTRON XAI — Chrome Extension (v1.0)
## 世界初：本家Google Gemini ✕ ディープラーニング思考プロセス完全透明化コックピット

本パッケージは、Google Gemini（本家 `https://gemini.google.com/app`）の画面に一切手を加えることなく、隣のサイドパネルで**リアルタイムにAIの思考プロセス・出処データ（Web/学習知識/ローカルコード）・物理パラメータをミリ秒同期で可視化するChrome拡張機能**です。

---

### 📦 インストール手順（わずか30秒・1回のみ）

1. **ZIPファイルを展開（解凍）する**:
   - ダウンロードした `GENESIS_muTRON_XAI_Chrome_Extension_v1.0.zip` を、お好きなフォルダに解凍します。
2. **Chromeの拡張機能画面を開く**:
   - Google ChromeのURLバーに以下を入力してEnterを押します。
     ```text
     chrome://extensions/
     ```
3. **デベロッパーモードをONにする**:
   - 画面右上にある **「デベロッパーモード」** のスイッチを **ON** にします。
4. **拡張機能を読み込む**:
   - 画面左上に現れる **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
   - 先ほど解凍したフォルダ（`manifest.json` が入っているフォルダ）を選択します。
   - ➔ **「GENESIS μTRON XAI」** が登録されます！

### 🚀 使い方 ＆ 評価時の見どころ

1. **Geminiを開く**:
   - **[https://gemini.google.com/app](https://gemini.google.com/app)** を開きます。
2. **サイドパネルを起動する**:
   - ブラウザ右上のツールバーにある **パズルピース（🧩）アイコン** をクリックし、**「GENESIS μTRON XAI」** をクリックします。
   - ➔ Geminiの右隣にスッとサイドパネルが開きます。
3. **質問を入力・送信する**:
   - Geminiに普段通り質問を入力して送信（Enterキー）してください。
     - *おすすめ評価クエリ例*:
       - `生体脳と同じ機能を持つ機械脳を作るには、どのような仕組みや機能を持たせたらいいのかな？`
       - `自動運転ドローンの旋回制御の異常とジャイロ力学について調べて`
       - `耐量子暗号とShorの素因数分解アルゴリズムの脆弱性を教えて`
4. **ここを見てほしい！（評価ポイント）**:
   - **0秒同期**: 左で送信した瞬間、右のパネルが質問を自動キャッチします。
   - **Gemini回答との1対1対応**: Geminiの回答の第1章・第2章の論理的根拠、Nature論文抜粋、物理パラメータ、ローカルコード行番号がリアルタイムに表示されます。
   - **👁️ アニメ非表示ボタン**: 実務や詳細確認時は、右上ボタンでアニメを折りたたみ、画面100%をログ全開にできます。
   - **📄 Google Docs 保存**: 思考ログと監査証跡を1クリックで公式Googleドキュメントにエクスポートできます。
